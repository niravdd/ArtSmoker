## 📌 0. Обзор

Простой и удобный для художников интерфейс к моделям генерации изображений и видео Amazon Bedrock. ArtSmoker помогает творческим командам эффективно использовать Bedrock — без необходимости изучать API, CLI или промпт-инженерию.

### 📝 Проблема

Творческие команды и игровые студии хотят использовать ИИ для генерации ассетов, но сталкиваются с реальными препятствиями:

- **Нет простого интерфейса** — художникам не нужно входить в консоль Bedrock или писать API-вызовы для генерации изображений
- **Промпт-инженерия сложна** — составление эффективных промптов с правильными негативными промптами, стилевыми директивами и форматированием под конкретную модель требует экспертизы, которой у большинства художников нет
- **Команды не создают/обучают собственные модели** — им нужен доступ к множеству моделей, уже доступных на Bedrock, через инструмент, который они реально могут использовать
- **Редактирование изображений недоступно** — инпейнтинг, аутпейнтинг, поиск и замена, перенос стиля — всё требует знания API
- **2D-в-3D — отдельный конвейер** — чтобы получить из 2D-концепта текстурированную 3D-модель, готовую для игрового движка, обычно нужно ручное моделирование, UV-развёртка и покраска текстур — или дорогие сторонние инструменты

### 📝 Решение

ArtSmoker — это самостоятельно размещаемое веб-приложение, которое оборачивает Amazon Bedrock в удобный творческий интерфейс. Специально разработано для производства игровых ассетов, но также применимо в других творческих индустриях — рекламе, электронной коммерции, издательском деле и цифровых медиа, где ценен визуальный контент, созданный ИИ.

- **Художники просто описывают, что им нужно** на обычном языке — ArtSmoker за кулисами занимается декомпозицией промптов, улучшением, оптимизацией под модель и применением стиля. Управляемый Prompt Designer позволяет пользователям тонко настраивать отдельные визуальные элементы (субъект, сцена, освещение, цвета) с помощью переключателей «зафиксировать/варьировать» для создания действительно различных творческих вариантов
- **Генерация с учётом стиля** — загрузите существующие работы вашей игры, и модели зрения ArtSmoker изучат вашу визуальную идентичность. Каждый сгенерированный ассет соответствует облику вашей игры
- **Все модели Bedrock, все регионы** — полностью настраиваемо. Выбирайте модели text-to-image, видеомодели и регионы. Система динамически обнаруживает доступные модели через Bedrock API
- **Self-hosted модели с открытым кодом — развёртывание в 1 клик** — просмотрите курируемый каталог предварительно протестированных моделей (HunyuanImage 3.0, FLUX.2 и другие), выберите GPU-инстанс и разверните на Amazon SageMaker одним кликом. Всё обрабатывается автоматически: упаковка инференса, квантизация, настройка CUDA, автомасштабирование и отслеживание заданий. Каждая модель в каталоге валидирована от начала до конца перед выпуском
- **Изображение в 3D одним кликом** — генерируйте текстурированную 3D-модель (GLB) непосредственно из любого 2D-ассета или изображения персонажа. Мультиракурсный синтез и запекание текстур создают меши, готовые для игрового движка, которые импортируются напрямую в Unity, Unreal или Blender — без ручного моделирования
- **Ваш AWS-аккаунт, ваша IP** — всё работает в вашем собственном приватном AWS-аккаунте. Все работы, промпты, стили и сгенерированные ассеты остаются в вашей изолированной среде — никакие данные не уходят в сторонние сервисы. Вы сохраняете полное право собственности и контроль над своей творческой IP

**Модели Amazon Bedrock**: Claude Sonnet/Opus (промпт-инженерия и чат), Nova Canvas, Titan Image, Stable Diffusion 3.5 Large, Stable Image Ultra, Stability AI (редактирование изображений), Nova Reel, Luma AI Ray (генерация видео), а также более 80 LLM от 16 провайдеров для Chat Studio. **Self-hosted модели**: HunyuanImage 3.0 (BF16/NF4), FLUX.2, FLUX.1, TripoSG и другие через Amazon SageMaker — с расширяемым каталогом для добавления новых моделей.

## 📌 1. Возможности

ArtSmoker работает в двух режимах — **автономный** (без настройки художественного стиля или темы, просто опишите и генерируйте) и **с направляющим стилем** (загрузите существующие работы, и каждая генерация будет соответствовать вашей визуальной идентичности). Оба режима используют одни и те же студии и конвейер генерации.

### 📝 Автономный режим (быстрый старт)

Не нужна настройка стиля или темы — откройте 2D Image Studio, Video Studio или Type Studio и начните создавать.

1. **Опишите, что вам нужно** — введите промпт, например «hospital building» или «fire mage character», или используйте голосовой ввод. ИИ декомпозирует вашу идею на визуальные компоненты, улучшает её оптимизациями под конкретную модель и учитывает ваш творческий замысел через умные переключатели «зафиксировать/варьировать». Пишите на любом языке — промпты на других языках автоматически переводятся.
2. **Выберите модели и настройки** — мультиселект из всех доступных моделей text-to-image (Amazon Bedrock + self-hosted на SageMaker), выберите размеры, уровень качества и регион. Отметьте несколько моделей для сравнения бок о бок или выберите одну для целенаправленной генерации. Оценка стоимости обновляется в реальном времени.
3. **Получите действительно разные варианты** — система генерирует до 5 принципиально разных творческих концепций (варьируя костюм, настроение, освещение, композицию — а не просто ракурс камеры), каждая с 5 вариациями сидов (всего 25 изображений). Указанные пользователем детали фиксируются; детали, определённые ИИ, смело варьируются.
4. **Редактируйте и дорабатывайте** — используйте инпейнтинг, аутпейнтинг, стирание, поиск и замену или перекраску прямо в Asset Viewer. Каждая правка создаёт новую версию — оригинал всегда сохраняется.
5. **Скачайте файлы, готовые для игры** — PNG с прозрачным фоном + SVG с описательными именами (например, `hospital-building_opt2_var3.png`). Видео экспортируется в MP4.

### 📝 Режим с направляющим стилем (соответствие вашему художественному стилю и теме)

Для команд, которые хотят, чтобы каждый сгенерированный ассет соответствовал существующему художественному стилю — загрузите референсные изображения и позвольте ИИ изучить вашу визуальную идентичность.

1. **Загрузите арт вашей игры** — импортируйте референсные изображения из локальных директорий (рекурсивное сканирование, символические ссылки для избежания дублирования) или S3-бакетов (рекурсивный листинг с пагинацией). **Умная дедупликация** запускается автоматически — удаляет варианты поворотов (barrel_N/E/S/W.png оставляет только barrel_S.png) и кадры анимации (Idle0-Idle8 оставляет только Idle). Например, изометрический набор ассетов из 747 файлов дедуплицируется до ~99 уникальных объектов. Поддерживаются: .png, .jpg, .jpeg, .gif, .bmp, .webp, .tiff, .tif, .tga, .ico, .svg, а также автоматическое извлечение текстур из 3D-моделей (.glb, .gltf).
2. **ИИ изучает ваш стиль** — двухфазный анализ с учётом связности: сначала быстрая проверка определяет, является ли ваша коллекция единой, структурно согласованной или разнородной. Затем глубокий анализ полного набора референсов создаёт профиль стиля с богатыми метаданными — цветовые палитры, толщина линий, паттерны освещения, правила композиции и производственные соглашения. Если вы предоставите подсказки для генерации, ИИ получит их как «Руководство художника», чтобы анализ понимал не только видимое, но и намерение.
3. **Генерация с применённым стилем** — когда вы выбираете стиль в Image Studio, каждый промпт автоматически обогащается визуальными директивами вашего стиля. Промпт «hospital building» превращается в детальную инструкцию генерации, включающую цветовую палитру вашей игры, соглашения о перспективе и стиль рендеринга.
4. **Всё из автономного режима применимо** — множественные варианты, сравнение моделей, редактирование, версионирование и скачивание файлов, готовых для игры — всё работает так же, теперь направляемое вашим художественным стилем.

> [!NOTE]
> Весь сгенерированный контент создаётся моделями ИИ и зависит от предоставленных вами промптов и референсов. Пожалуйста, ознакомьтесь с [отказом от ответственности](#disclaimer) относительно качества контента, интеллектуальной собственности и применимых условий обслуживания перед использованием сгенерированных ассетов в продакшене.

### 📝 1.1 Обзор возможностей

- 🎨 **Style Library** — Загрузите арт, ИИ изучит вашу визуальную идентичность
- 🖼️ **2D Image Studio** — Генерация изображений с вариантами x вариациями, направляемый 3-шаговый рабочий процесс промптов
- 🎨 **Prompt Designer** — ИИ разбирает ваш промпт на редактируемые визуальные компоненты (субъект, сцена, освещение, цвета) с переключателями «зафиксировать/варьировать» для каждого поля, интеграцией стиля и умной классификацией типа ассета. Photorealistic, Character, Environment и другие
- 🎬 **Video Studio** — Текст-в-видео с модель-специфичными подсказками (камера Nova Reel, естественный язык Luma Ray), мультишот, изображение-в-видео
- ✍️ **Type Studio** — Текстовые оверлеи, спроектированные ИИ, с выбором шрифтов
- 💬 **Chat Studio** — Мультимодельный LLM-чат со стримингом, Markdown, подсветкой кода, зрением, сессиями, компактификацией контекста
- 📁 **Единая галерея** — Просмотр изображений + видео, фильтр по медиа, поиск, скачивание, удаление
- ✏️ **Редактирование изображений** — Инпейнтинг, аутпейнтинг, стирание, поиск и замена, перекраска (в AssetViewer)
- 🔄 **Прогресс в реальном времени** — SSE-стриминг с видимостью повторов/троттлинга
- 🛡️ **Умная модерация** — Канареечное тестирование, автопереключение моделей, переписывание с помощью ИИ
- ⚙️ **Model Registry** — Админ-интерфейс по студиям (Image, Video, Chat, Type, Shared), обнаружение Bedrock, поддержка пользовательских моделей
- 📝 **Prompt Templates** — 19 редактируемых директивных промптов LLM, доработка с помощью ИИ, валидация переменных с автоисправлением
- 📦 **Версионирование ассетов** — Редактирование на месте с историей версий (v1, v2, ...) и навигацией по версиям
- 💰 **Отслеживание расходов** — Оценочные расходы AWS за запрос, за сессию, за ассет — отправляются в телеметрию PulseBoard
- 🌐 **i18n на 8 языках** — Полный перевод интерфейса (EN, JA, ZH, KO, HI, RU, FR, ES), автоопределение неанглийских промптов, двуязычный предпросмотр
- 🔍 **Поддержка пользовательских моделей** — Автоматическое обнаружение дотюненных, импортированных и развёрнутых пользовательских моделей Bedrock
- 🔧 **Self-Hosted Models — развёртывание в 1 клик** — Просмотрите курируемый каталог предварительно протестированных моделей с открытым кодом (HunyuanImage 3.0, FLUX.2, FLUX.1, TripoSG и другие), выберите GPU-инстанс и нажмите Deploy. ArtSmoker обрабатывает всё: упаковку обработчика инференса, настройку квантизации, выбор нужного CUDA-тулкита, настройку автомасштабирования, регистрацию алармов CloudWatch и связывание асинхронного отслеживания заданий. Каждая модель в каталоге валидирована от начала до конца — от холодного старта через генерацию до доставки в галерею. Поддерживает BF16 + FlashInfer для лучшего качества, NF4 для экономии, автоопределение мульти-GPU, автомасштабирование до нуля ($0 в простое), одна и та же модель работает на разных типах инстансов без перенастройки
- 🧊 **Генерация 3D из изображений** — Конвертируйте любое изображение Game Asset или Character в текстурированный 3D-меш (GLB) одним кликом. Многоракурсный синтез + запекание текстур создаёт ассеты, готовые для игрового движка. Интерактивный 3D-просмотрщик с орбитой/зумом/панорамированием
- 🔄 **Auto-Update** — Версионированный git pull при запуске, авторестарт при обновлении, периодическая проверка каждые 24 часа (`ARTSMOKER_AUTO_UPDATE=false` для отключения)

### 📝 1.3 Двухуровневая генерация

Для каждого промпта ИИ создаёт **варианты (Options)** — принципиально разные дизайнерские интерпретации (например, для «warrior»: берсерк-викинг, японский самурай, племенной воин, кибер-солдат, греческий гоплит). Для каждого варианта модель изображений создаёт **вариации (Variations)** — разные случайные сиды, дающие тонкие визуальные различия. Это даёт художникам широкую творческую палитру для выбора.

### 📝 1.4 Мультимодельный выбор

Выпадающий список моделей поддерживает **мультиселект с чекбоксами** — выберите любую комбинацию моделей для одного запуска генерации:

- **Одна модель** — отметьте одну модель для целенаправленной генерации (самый быстрый, самый дешёвый вариант)
- **Несколько моделей** — отметьте 2-3 модели для целенаправленного сравнения (например, только SD 3.5 + FLUX.2)
- **All Available Models** — переключатель внизу выделяет/снимает выделение со всех включённых моделей для полного сравнения бок о бок

Каждая модель работает независимо: если строгие модели блокируют промпт, вы всё равно получаете результаты от моделей, которые его приняли. Оценка стоимости обновляется в реальном времени при выборе/снятии моделей.

Опциональный переключатель **«Model-optimized prompts»** адаптирует промпт под сильные стороны каждой модели — промпты переписываются для каждой модели (например, бустеры качества для SD 3.5, естественный язык для FLUX.2, краткие описания для Nova Canvas).

### 📝 1.5 Video Studio

Генерация ИИ-видео и анимаций из текстовых промптов. Поддерживает **Amazon Nova Reel** (v1.0, v1.1) и **Luma AI Ray** (v2.0).

| Возможность | Nova Reel | Luma Ray v2 |
|-------------|-----------|-------------|
| **Макс. длительность** | 120 сек (2 минуты) | 9 секунд |
| **Разрешение** | 1280x720 | 720p / 540p |
| **Соотношения сторон** | Только 16:9 | 7 вариантов (1:1, 16:9, 9:16 и др.) |
| **Изображение-в-видео** | Да (начальный кадр) | Да (начальный + конечный кадр) |
| **Зацикленное видео** | Нет | Да |
| **Мультишот-управление** | Да (авто + ручной) | Нет |
| **Цена** | ~$0.08/сек | ~$1.50/сек |

**Как это работает:**
1. Выберите видеомодель и настройте длительность, соотношение сторон, регион
2. Введите промпт — ИИ обогащает его кинематографической лексикой, движениями камеры и подсказками временной когерентности
3. Нажмите Generate — задание выполняется асинхронно через `StartAsyncInvoke`, результат направляется в ваш настроенный S3-бакет
4. Опрос статуса каждые 5 секунд — по завершении извлекается миниатюра (через ffmpeg) и MP4 скачивается локально (или стримится из S3)
5. Видео появляются как в разделе «Recent Videos» Video Studio, так и в единой галерее

**Требуется S3-бакет**: Генерация видео выводит результат в S3. Настроить можно через Video Settings в интерфейсе (просмотр существующих бакетов или создание нового) или через CLI:

```bash
# Создайте S3-бакет для хранения видео (замените REGION и YOUR_ORG)
aws s3api create-bucket --bucket artsmoker-video-YOUR_ORG --region us-east-1

# Для регионов, отличных от us-east-1, добавьте LocationConstraint:
aws s3api create-bucket --bucket artsmoker-video-YOUR_ORG --region us-west-2 \
  --create-bucket-configuration LocationConstraint=us-west-2
```

Режим хранения: локальное скачивание (по умолчанию) или стриминг из S3 по запросу.

**Улучшение видеопромптов**: LLM добавляет движения камеры (панорама, зум, наезд, слежение), детали освещения и временные подсказки. Поскольку видеомодели не поддерживают негативные промпты, концепции избегания естественно вплетаются в позитивный промпт.

### 📝 1.6 Chat Studio

Полнофункциональный LLM-чат — как собственный разговорный ИИ, работающий на вашем AWS-аккаунте без стороннего доступа к данным.

**Более 80 моделей от 16 провайдеров** — Claude (Sonnet, Opus, Haiku), Amazon Nova, Meta Llama, Mistral, Cohere, Qwen, DeepSeek, Google Gemma, NVIDIA Nemotron и другие. Плюс любые пользовательские/импортированные модели в вашем аккаунте. Все обнаруживаются автоматически через Sync from AWS.

**Основные возможности:**
- **Потоковые ответы** — рендеринг токен за токеном в реальном времени через Bedrock ConverseStream
- **Рендеринг Markdown** — заголовки, жирный/курсив, списки, таблицы, цитаты, горизонтальные линии
- **Блоки кода** — подсветка синтаксиса (highlight.js) со значком языка + кнопкой копирования
- **Метрики по сообщениям** — входные/выходные токены, задержка, оценочная стоимость, использованная модель
- **Индикатор контекстного окна** — визуальный индикатор заполнения (зелёный/жёлтый/красный) с использованным/максимальным количеством токенов
- **Переключение регионов** — каждая модель показывает все доступные регионы, выбирайте ближайший или дешёвый

**Управление сессиями:**
- Несколько параллельных сессий с автосохранением
- Переименование, дублирование, удаление, поиск/фильтр в боковой панели
- Экспорт диалогов в Markdown
- Итоги сессии: количество токенов, оценочная стоимость, количество сообщений

**Расширенные возможности:**
- **Шаблоны системных промптов** — General Assistant, Coding Expert, Creative Writer, Game Designer, Data Analyst, Technical Writer
- **Зрение/мультимодальность** — перетаскивание, выбор файлов или вставка изображений через Ctrl+V для моделей с поддержкой зрения
- **Компактификация контекста** — ИИ суммирует старые сообщения для освобождения пространства контекстного окна
- **Повторная генерация** — перезапуск любого ответа ИИ с тем же промптом
- **Редактирование и переотправка** — изменение любого сообщения пользователя и повтор с этой точки
- **Ответвление** — разветвление диалога от любого сообщения в новую сессию

**Прозрачность ценообразования:** выбор моделей показывает стоимость за 1K токенов, информационная панель показывает оценочную стоимость для диалогов на 10K и 100K токенов.

### 📝 1.7 Учёт типа ассета

Выбранный **тип ассета** принципиально меняет то, как ИИ интерпретирует ваш промпт — не только модель изображений, но и каждый этап конвейера. Когда вы вводите «hospital» и выбираете разные типы ассетов, вы получаете совершенно разные результаты:

| Тип | Композиция | Кадрирование | Технический подход |
|-----|-----------|-------------|-------------------|
| **Game Asset** | Единичный изолированный объект на прозрачном фоне. Без сцены, текста, UI. | Прямой или изометрический ракурс, объект занимает 70-80% кадра. | Чёткие резкие края для удаления фона, единообразное освещение сверху-слева, без теней на земле. Спроектирован для компоновки с другими игровыми ассетами в различных масштабах. |
| **Character** | Полнофигурный или 3/4 фигуры, изолированный на чистом фоне. Только один персонаж. | Персонаж занимает 60-75% по вертикали, от головы до ног, слегка смещён от центра. | Сильный читаемый силуэт (узнаваем по одному силуэту), выразительная поза, передающая характер, чёткие черты лица и детали костюма. |
| **Icon** | Единичный жирный узнаваемый символ, центрированный с щедрым отступом. Максимальная простота. | Вид спереди или лёгкий наклон 3/4, свободное пространство по краям. | Должен чётко читаться при 64x64 пикселях. Высокий контраст, максимум 3-5 цветов, жирные формы, без тонких линий или мелких деталей. |
| **Marketing Banner** | Полная сценическая иллюстрация с драматичной композицией. Чистая безопасная зона для текста на одной стороне — без отрендеренного текста или типографики. | Широкий кинематографический вид, камера отодвинута для показа сцены. | Богатые насыщенные цвета, драматичное освещение (контурный свет, объёмные лучи), глубина резкости. ИИ явно инструктирован НЕ рендерить текст; зона для текста оставлена чистой для постпродакшн-наложения в инструментах дизайна (Figma, Canva и т.д.). |
| **Environment** | Полный ландшафт с передним/средним/задним планами глубины, направляющими линиями. | Широкий установочный кадр, горизонт в верхней или нижней трети. | Атмосферная перспектива (дальние объекты светлее/размытее), повествование через детали среды, освещение, задающее настроение. |

Это важно на каждом этапе:

- **Кнопка «Preview Enhanced Prompt»** — При нажатии Compose ИИ использует тип ассета, чтобы преобразовать ваше краткое описание в детальный промпт генерации, сочетая ваши слова с директивами стиля и типа ассета. Ваше явное намерение всегда имеет приоритет над стилевыми настройками по умолчанию. Вы можете просмотреть составленную версию перед генерацией.
- **Генерация концепций** — При генерации нескольких вариантов ИИ создаёт N различных дизайнерских интерпретаций, все из которых соблюдают структурные правила типа ассета. У варианта Character всегда читаемый силуэт; у варианта Marketing Banner всегда есть зона для текста без отрендеренного текста.
- **Результат** — Два изображения из одного промпта, но с разными типами ассетов будут выглядеть совершенно по-разному. Game Asset «warrior» — это одиночный центрированный спрайт персонажа. Marketing Banner «warrior» — это эпическая батальная сцена с чистой зоной для заголовка.

### 📝 1.8 Генерация 3D-моделей (Image-to-3D)

Генерация готовых к производству, полностью текстурированных 3D-мешей из любого 2D-изображения — прямо в Asset Viewer. Выберите изображение **Game Asset** или **Character**, откройте вкладку **3D Model** и нажмите Generate. Результат — готовый для игрового движка GLB, который можно вращать, масштабировать и скачивать — без ручного моделирования, UV-развёртки и рисования текстур.

**Сгенерированная модель — вращайте, изучайте, скачивайте:**

![Генерация 3D-модели — сгенерированный меш солдата в интерактивном 3D-просмотрщике с разных ракурсов](docs/images/3d-model-result.png)

Одно 2D-изображение персонажа (слева, во вкладке PNG) превращается в полностью текстурированный 3D-меш, который можно свободно вращать прямо в браузере. Вкладка **3D Model** теперь также перечисляет точные **модели и инструменты**, использованные для создания каждого ассета (модель геометрии, бэкенд текстурирования, тип вывода, инстанс и параметры генерации) — они сохраняются в метаданных ассета для полной прослеживаемости.

**Как это работает:**

1. **Извлечение геометрии** — трансформер с выпрямленным потоком (TripoSG, 1,5 млрд параметров, лицензия MIT) конвертирует одно 2D-изображение в высокоточный 3D-меш, используя представление в виде знакового поля расстояний (SDF). Плотность меша масштабируется в зависимости от пресета качества (до ~1 млн полигонов при максимальном октодеревном разрешении) для чёткой детализации лиц и снаряжения.
2. **Текстурирование** — меш закрашивается **бэкендом текстурирования, который вы выбираете при развёртывании**. По умолчанию используется **TRELLIS.2** (Microsoft, MIT) — текстуризатор с SLAT/воксельным кондиционированием, создающий полные PBR-материалы (базовый цвет + металличность-шероховатость + альфа) в атласе 4096², по качеству не уступающий лучшим проприетарным текстуризаторам и при этом доступный для коммерческого лицензирования.
3. **PBR-вывод** — текстурированный меш экспортируется в GLB со встроенными PBR-картами, готовый к физически корректному рендерингу в любом современном движке.

**Выбирайте бэкенд текстурирования — с лицензией на виду.** Image-to-3D поддерживает три текстуризатора, выбираемых для каждого развёртывания. Каждый из них показывает в диалоге развёртывания **полную разбивку лицензий и зависимостей** — каждую загружаемую модель, её лицензию и то, разрешена ли она для коммерческого использования или ограничена — и вы должны прочитать и принять условия перед развёртыванием:

| Бэкенд | Лицензия | Коммерческое использование | Лучше всего для |
|--------|----------|----------------------------|-----------------|
| **TRELLIS.2** *(по умолчанию)* | MIT | ✅ Да — требует указания «Built with DINOv3» в вашем продукте | Продакшн, коммерческие ассеты, наивысшее качество |
| **Hunyuan3D-Paint** | Tencent Community | ❌ Некоммерческое | Исследования / некоммерческое использование, исключительные лица |
| **MVPainter** | Apache-2.0 | ✅ Да | Лёгкое коммерческое многоракурсное запекание |

Удаление фона (этап вырезания перед текстурированием) по умолчанию использует **BiRefNet (MIT)** — полностью чистый для коммерческого использования — с некоммерческой альтернативой (RMBG), доступной как явно раскрываемая опция. ArtSmoker никогда не загружает ограниченную зависимость молча: всё, что ограничено или некоммерческое, именуется, помечается значком и доступно только после явного принятия условий.

**Результат:** Стандартный формат GLB со встроенными PBR-текстурами — импортируется напрямую в Unity, Unreal Engine, Blender и другие игровые движки. Интерактивный 3D-просмотрщик поддерживает орбиту, зум и панорамирование для мгновенной проверки, а вкладка **3D Model** перечисляет точные модели и инструменты, использованные для каждого ассета (модель геометрии, бэкенд текстурирования, зависимости, инстанс, параметры) для полной прослеживаемости.

**Инфраструктура:** Развёртывается через тот же поток Custom Models в 1 клик, при этом селектор бэкенда на этапе развёртывания показывает для каждого варианта лицензию, таблицу зависимостей, базовый инстанс и ориентировочную стоимость/время. Работает на GPU-инстансах `ml.g6e`; масштабирование до нуля в простое — $0 между заданиями. Первый холодный запуск один раз собирает CUDA-расширения (затем они кэшируются в S3 для быстрых перезапусков).

| Метрика | Значение |
|---------|----------|
| Качество меша | До ~1 млн полигонов, полные нормали вершин |
| Разрешение текстуры | PBR-атлас 4096² (базовый цвет + металличность-шероховатость + альфа) |
| Лицензирование | По умолчанию пригодно для коммерческого использования (TRELLIS.2 MIT + BiRefNet MIT); некоммерческие бэкенды предлагаются с полным раскрытием |
| Поддерживаемые типы ассетов | Game Asset, Character |

### 📝 2.1 Учётные данные AWS

ArtSmoker использует [стандартное разрешение учётных данных boto3](https://boto3.amazonaws.com/v1/documentation/api/latest/guide/credentials.html#configuring-credentials), поэтому подходит любой из следующих методов:

| Метод | Подходит для | Как |
|-------|-------------|-----|
| **Переменные окружения** | CI/CD, контейнеры | `AWS_ACCESS_KEY_ID` + `AWS_SECRET_ACCESS_KEY` |
| **Файл общих учётных данных** | Локальная разработка | `~/.aws/credentials` через `aws configure` |
| **Именованный профиль** | Несколько аккаунтов | Установите `ARTSMOKER_AWS_PROFILE=myprofile` или `AWS_PROFILE` |
| **AWS SSO** | Корпоративный SSO | `aws configure sso` |
| **IAM Instance Profile** | EC2, ECS, App Runner | Прикрепите IAM-роль к инстансу — учётные данные на машине не нужны |
| **ECS Task Role** | Контейнеры ECS/Fargate | Назначьте роль выполнения задачи с необходимыми разрешениями |

Быстрая проверка работоспособности учётных данных:

```bash
aws sts get-caller-identity
```

> [!NOTE]
> На EC2 и других вычислительных сервисах AWS вам не нужно настраивать явные учётные данные. Прикрепите [IAM Instance Profile](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_roles_use_switch-role-ec2_instance-profiles.html) с необходимыми разрешениями, и boto3 автоматически подхватит его через сервис метаданных инстанса.

Подробные разрешения IAM, инструкции по установке, параметры конфигурации и информацию о ценах см. в разделах 2.1.1–2.4, разделах 3–4 и разделах 11–12 [англоязычного README](README.md).

## 📌 8. Модель безопасности

ArtSmoker спроектирован как **инструмент разработки для локальной/доверенной сети** — работает на машине разработчика или приватном EC2-инстансе.

- **Без аутентификации** — все API-эндпоинты открыты. Подходит для локальной разработки и приватных командных развёртываний.
- **Браузер файловой системы** — эндпоинт `GET /api/browse/local` позволяет просматривать любую директорию, к которой имеет доступ серверный процесс. Это сделано намеренно для импорта референсного арта.
- **Доступ к S3** — Просмотр и импорт S3 используют учётные данные AWS сервера.

> [!WARNING]
> Не выставляйте ArtSmoker в недоверенные сети без добавления аутентификации и ограничений путей. См. [дорожную карту развёртывания в SPEC.md](SPEC.md#14-deployment--scaling-roadmap) для рекомендаций по укреплению продакшена.
